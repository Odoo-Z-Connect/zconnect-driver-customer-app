# Contributing to ZConnect Mobile

1. Follow the [Setup](docs/SETUP_AND_DEVELOPMENT.md) guide to get started.
2. Create a feature branch off `dev`.
3. Adhere to the existing design system (`AppColors`, `ZCButton`, etc. in `lib/core` and `lib/shared`).
4. Ensure `flutter format .` and `flutter analyze` pass.
5. Submit a PR.
