# Known Issues & Roadmap

## Implemented
- Customer signup and UI shells.
- Driver dashboard and job detail views.
- Interactive Location Pin-Drop (OpenStreetMap).
- Delivery Progress Timeline and Status Chips.
- Google Maps Intent Navigation (via `launchUrl`).

## Known Issues
- Network instability with the local Odoo backend can occasionally cause silent fallbacks to local mocked data.

## Roadmap
- **Live GPS**: Implement driver location tracking and broadcasting.
- **Payments**: Integrate a payment gateway for customer shipments.
- **Push Notifications**: Integrate Firebase Cloud Messaging (FCM) for real-time driver job assignments.
